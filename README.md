# Team 20 Countdown
This code allows the Team 20 Countdown to run. All commented code is the original creator's.
The code should run on any Raspberry Pi 3/4/5 with the proper hardware.

The hardware needed:
- Raspberry Pi 3 Model B+ (other recent models may also work)
- Adafruit RGB Matrix + Real Time Clock HAT
- Brass M2.5 Standoffs for Pi HATs (optional)
- 1–3 64x32 RGB LED Matrix panels (3–6mm pitch)
- 5V 4000mA Switching Power Supply
- CR1220 3V battery
- Soldering iron
- MicroSD memory card, 4GB or larger (make sure you don't need its contents!)
- Computer running Mac OS, Windows, or Linux, with a MicroSD card reader or slot
- Ethernet cable connection to the internet
